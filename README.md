### 🚀 Featured Projects

#### 🧴 [Skin Microbiome Analysis (L'Oréal Data)](https://github.com/AlanaAnnaman/loreal-skin-microbiome)
*Analyzed 18,036 raw 16S rRNA sequencing reads from a human cheek swab.*
*   Built an end-to-end QIIME2/DADA2 pipeline, retaining 89.4% of high-quality reads.
*   Bypassed scikit-learn version mismatches by implementing a VSEARCH consensus taxonomy workflow.
*   **Result:** Identified 23 unique ASVs, confirming *Cutibacterium acnes* as the dominant taxon (82% relative abundance).

#### 🦠 [Ebola Single-Cell Transcriptomics](https://github.com/AlanaAnnaman/90-day-bioinformatics-sprint)
*Characterized the host immune response to Ebola virus using R and Seurat.*
*   Analyzed 42,881 single cells from infected primates and identified 18 immune cell populations.
*   Diagnosed and corrected data-processing errors that had inflated cell counts by over 100x, restoring alignment with published clinical markers.
*   Quantified a +11.3% neutrophil expansion and -16.2% monocyte depletion during infection.

#### 💊 [Antimicrobial Resistance Prediction](https://github.com/AlanaAnnaman)
*Built a machine learning pipeline to predict ciprofloxacin resistance in E. coli.*
*   Engineered genomic features from 15,827 bacterial genomes (BV-BRC).
*   Achieved 90% accuracy and 0.92 ROC-AUC using XGBoost.
